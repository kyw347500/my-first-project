# 원미 프라임 부동산 브리핑

홍길동부동산의 원미구 아파트 브리핑 대시보드입니다. Node.js 18 이상에서 실행할 수 있습니다.

## 실행

```powershell
node server.mjs
```

브라우저에서 `http://localhost:4173`을 여세요. 공공데이터포털 서비스 키는 `.env`에 두며, 이 파일은 Git에서 제외됩니다. 새로 실행할 때는 `.env.example`을 복사해 `.env`를 만들고 `DATA_GO_KR_SERVICE_KEY`를 입력하세요. 외부에 배포할 때는 키를 프런트엔드에 넣지 말고 호스팅 환경변수 `DATA_GO_KR_SERVICE_KEY`를 설정하세요.

## 데이터 범위와 표시

- 매매와 전월세 실거래는 국토교통부 아파트 실거래 API를 서버에서 조회합니다. 지역 코드는 부천시 원미구(41192)입니다.
- 기간 선택은 주간·월간·직접 지정이 가능하며, 원천 API의 월별 응답을 선택 기간으로 걸러 표시합니다.
- 한국부동산원 API 키는 전달되지 않아 가격지수 등은 아직 API 연결 전입니다. 시장 요약 카드의 일부 지표와 추천 매물은 화면 시연용 예시값입니다.
- 실거래 원본에는 단지 좌표가 포함되지 않아 지도 핀은 단지 인근의 대표 위치 예시입니다. 거래 가격·날짜는 API 응답을 사용하며, 샘플 상태일 때는 화면에 샘플 데이터로 표시됩니다.
- 동 선택은 원천 API의 법정동명과 일치하는 거래만 남깁니다. 원천 데이터는 신고 후 반영 시차가 있을 수 있습니다.

추천 매물은 브라우저의 로컬 저장소에 저장됩니다.
