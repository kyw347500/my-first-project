# 원미구 저층주거 투자 브리핑

춘의동·도당동·원미동의 노후 단독·다가구주택 매입 후 상가주택 신축을 검토하기 위한 단일 화면 브리핑입니다. 아파트 거래 분석은 제외했습니다.

## 실행

Node.js 18 이상에서 실행합니다.

```powershell
node server.mjs
```

브라우저에서 `http://localhost:4173`을 여세요. 인증키는 `.env` 파일에 서버 전용으로 저장하며 브라우저로 전달하지 않습니다. `.env`는 Git에서 제외됩니다.

## 데이터 연결

- 국토교통부 단독·다가구 매매 실거래가 API: 최근 12개월, 법정동 춘의동·도당동·원미동 필터.
- 한국부동산원 R-ONE Open API: 통계표 카탈로그와 지역별 지가변동률 자료를 조회하고 부천시 관련 행을 표시합니다. 상업용 임대동향 통계표는 카탈로그에서 함께 확인합니다.
- 지도 배경은 Esri World Street Map 타일을 사용합니다. 학교·역·시장·산업시설은 공개 주소를 기준으로 표시하며 노후 저층주거 권역은 투자 검토용 개략 표시입니다. 개별 건축물의 사용승인연도나 특정 구역 경계를 나타내지 않습니다.
- 한국부동산원 상업용 임대동향은 표본·권역 통계이며 춘의·도당·원미 각 골목의 실제 임대료로 해석할 수 없습니다. 최신 공표일과 표본 범위는 R-ONE에서 확인하십시오.

## 참고

상가주택의 허용 용도, 용적률, 건폐율, 주차와 정비사업 중첩 여부는 필지별로 다릅니다. 매입 전에 토지이용계획확인서, 지구단위계획, 건축물대장, 정비구역 고시도와 현장 임대사례를 확인해야 합니다.
